# 개념영상 10편 검토 (2026-11-10)

## 만든 방식과 고른 것
- 이전 v2 영상(9초, SVG+sharp+FFmpeg)은 무게·온도·압력 편 안에 **움직이는 점(입자) 표현**이 남아 있었다. 활동 화면에서는 2026-11-08에 지웠지만 영상에는 그대로였다. 새 영상에는 점 표현이 없고, 공기의 흐름은 점선 화살로만 보인다.
- 6번 담당이 정한 A안("실험 노트")을 이 게임 말로 옮겼다: 크림색 모눈 노트 + 청록 잉크 + 금색 강조, 게임 소품 그림 그대로, 마지막에 바람여우 솔이(`soli.svg`)가 등장해 고개를 끄덕인다.
- 장면 하나당 4초(앱 자막 한 문장을 읽을 시간). 9초 → 12초로 늘리고 자막·장면 버튼·시간표를 한 데이터(`src/concept-clips.js`)로 묶었다.
- 만들지 않은 안: ① 캐릭터가 실험을 직접 하는 연기형(솔이 그림이 한 장뿐이라 포즈가 부족), ② 교과서식 도표형(이름표 대신 범례) — 둘 다 이 게임 화면과 거리가 멀어 제외.
- 소리: 앱이 자동재생을 위해 영상을 `muted`로 틀어서 넣어도 들리지 않는다. 영상 끝의 성공음은 앱이 이미 낸다 → 소리 트랙 없음.

## 가장 약한 장면
- **소화기 편**: 실험을 보여 줄 수 없는 내용이라(실제 소화기 실험 안 함) 움직임이 확인 표시와 소화기 이동뿐이다. 시간이 더 있으면 "타는 것을 돕는 기체(산소) / 돕지 않는 기체(이산화탄소)" 비교 카드를 같은 화면 안에서 바꿔 보이는 장면으로 다시 만들겠다.
- 탄산 편: 반복 기포가 마지막 장면에서 투명해져 포스터에 기포가 안 보였다 → 기포 세 개가 올라가다 멈추게 해 포스터에도 남겼다. 기포 크기가 작아 전자칠판 뒷자리에서 잘 보일지는 확인 못 했다.
