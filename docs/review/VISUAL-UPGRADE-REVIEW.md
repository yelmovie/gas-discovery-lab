# 주요 개념 그림 고도화 · 2026-10-28

시작·지도·시설 소개·20개 의뢰·개념 영상·코어 복구·결과·인증서의 시각 자료를 점검했다. 기존 배경·캐릭터·저울·밀폐 용기 등은 이미 프로젝트 화풍의 이미지로 제공되고 있었다. 허술한 도형 중심 표현은 다음과 같이 개선했다.

| 영역 | 개선 |
| --- | --- |
| 바람길·공작소 부품 | 일자 관·굽은 관·막힌 관을 독립 생성 이미지로 교체. 실제 연결 방향과 공기 흐름 경로는 코드로 제어. |
| 압력 실험 | 실린더 하우징과 플런저 이미지 분리. 플런저 위치·공기 공간 높이·16개 입자를 모델 값과 연결. |
| 온도 실험 | 풍선이 없는 병 이미지에 기존 풍선 하나만 연결. 같은 16개 입자가 풍선 내부에 남도록 배치. |
| 기체 이용 | 질소 포장·탄산음료는 기존 그림 활용. 산소 호흡 장치·CO₂ 소화기는 별도 생성해 조사와 성공 화면에 표시. |
| 풍선 자동차 | 단순 SVG 차를 생성 이미지로 교체. 바람은 뒤로, 자동차는 앞으로 향하는 연출 적용. |
| 중앙 코어 | 팬과 CSS 원형 장식 조합을 공기 분배 터빈 이미지로 교체. 전체 장치가 회전하지 않도록 작동 빛만 표현. |
| 팬 작동 | 고정 하우징과 회전 날개 이미지 분리. 받침대·보호망을 고정하고 날개만 회전. |
| 개념 영상 10종 | 새·기존 소품 이미지를 사용해 9초/1280×720/24fps 모션 그래픽 재제작. 자막은 DOM 유지. |

내장 image_gen을 사용했다. 생성본은 개별 투명 에셋이며 UI·글자·버튼을 이미지에 굽지 않았다. 원본은 `asset-bank/original/`, 웹용 12종은 `public/assets/visuals/`, 프롬프트·제작 정보는 `docs/review/IMAGE-GENERATION-PROMPTS.json`에 보관했다. 12종 합계는 625,202 bytes다. 사용 경로·크기·알파·SHA-256은 `public/assets/visuals/manifest.json`에 기록했다.

정답 판정·저장 키·시설 해금·앞서 개선한 클릭 흐름은 유지했다. 장면 전환 때 이미지가 입력을 가로채지 않도록 그림 레이어는 pointer-events를 받지 않는다. 피스톤 드래그 중 DOM을 교체하지 않으며 동작 감소 설정도 반영했다.

검증은 사용자 브라우저에 연결하지 않는 별도 임시 Chrome 컨텍스트에서 수행한다. 모델 테스트, 20개 의뢰 완주와 영상 재생·이어하기·재탐구·중간 이탈, 여섯 화면 크기, 영상 전체 디코딩과 해시, 프로덕션 빌드를 확인한다. 실물 태블릿과 QR 인앱 브라우저 검수·외부 배포는 이번 로컬 작업 범위에 포함하지 않는다.

완료 결과: 모델 테스트 20개, 20개 의뢰와 선택형 영상 → 코어 복구 → 인증서 전체 여정, 재탐구·키보드·중간 이탈 검사를 통과했다. 1280×800·906×755·1920×1080·1024×768·1440×900·873×580의 레이아웃 경고와 브라우저 오류는 없었다. 873×580 터치 컨텍스트에서 피스톤 드래그 → 정답 탭 → 완료, 온도 키보드 → 정답 탭, 16입자 보존·풍선 한 개·팬 하우징 고정/날개 회전을 별도로 확인했다. 30개 미디어 해시/크기, 20개 영상 파일 전체 디코딩과 프로덕션 빌드도 통과했다.
