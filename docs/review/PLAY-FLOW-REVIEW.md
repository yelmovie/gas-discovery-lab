# 조작 흐름 개선 · 2026-10-28

대상은 다섯 연구시설의 20개 의뢰와 중앙 코어 복구다. 기존 정답 조건, 연구 기록 형식, 시설 해금 조건을 유지하면서 반복 확인과 저장 조작을 줄였다. 새 이미지·음원·외부 의존성은 추가하지 않았다.

| 시설 | 변경 | 단순 성공 경로에서 줄인 조작 |
| --- | --- | --- |
| 바람 동력소 | 공기 공급 한 번 이후 관 회전마다 흐름 표시, 팬 작동 후 자동 기록 | 기록 1회, 실패마다 반복하던 공기 공급 |
| 무게 연구소 | 새 측정값을 유효한 이전 기록과 자동 비교, 같은 기록 중복 방지 | 기록 선택 2회 + 비교 1회 + 저장 1회 |
| 환경 관측소 | 기준 모습 준비, 손잡이·피스톤 조작 종료 시 자동 기록, 정답 즉시 완료 | 기록 2회 + 저장 1회 |
| 기체 배송소 | 기체와 성질이 모두 맞으면 즉시 배송 | 별도 연결 1회 + 저장 1회 |
| 공기 공작소 | 부품 한 번 누르면 맞는 칸에 조립, 첫 시험 이후 수정 즉시 재시험 | 클릭형 조립의 칸 선택 3회 + 저장 1회 |
| 중앙 코어 | 증거는 펼쳐 보기로 제공, 바로 내 장치 연결 가능 | 증거 팝업 열기·닫기 10회 |

실험 완료 화면은 활동을 가리지 않는 발견 카드, 다음 의뢰, 선택형 개념 영상으로 통일했다. 비교·조작 결과를 직접 본 뒤 사용자가 다음으로 이동한다. 성공 후 이전 초안을 제거해 재탐구는 새 실험으로 시작하며, 이어하기에는 다음 의뢰를 저장한다.

## 입력과 전환

- 바람길 버튼 DOM 유지로 키보드 포커스를 보존하고, 성공 연출 중 이탈하면 완료 타이머를 취소한다.
- 완료 카드로 초점을 옮겨 기존 선택지가 사라져도 Tab으로 다음 행동을 찾을 수 있다. Enter 연타로 다음 의뢰가 실행되지 않도록 완료 카드 자체에 초점을 둔다.
- 부품 클릭과 터치 드래그를 모두 지원한다. 오답은 선택·조립을 바꾸어 바로 다시 확인한다.
- 피스톤 드래그 중 SVG를 교체하지 않고 좌표를 갱신해 터치 대상과 touchend를 유지한다.
- 환경 조작 중 새로고침하면 마지막으로 확정한 조건으로 복원한다. 취소한 조작은 기록하지 않는다.
- 코어 펌프는 밸브를 연 뒤 사용할 수 있고, 포커스 이탈·창 전환·포인터 취소 때 누르기를 중지한다.
- 기존 색상·글꼴을 사용하고 동작 감소 설정을 존중한다. 작은 화면에서는 무게 비교 두 기록을 나란히 배치한다.

## 변경 파일

- `src/activities/{flow,weight,climate,delivery,engineering}.js`: 시설별 조작과 자동 완료.
- `src/main.js`, `src/ui.js`: 공통 결과, 이어하기, 재탐구, 코어 복구와 누르기 처리.
- `src/learning-ux.css`: 발견 카드와 작은 화면 배치.
- `src/settingsContent.js`: 새 조작 방식 안내.
- `package.json`, `src/data.js`: 1.2.0 표시와 오프라인 캐시 버전 갱신. 저장 키는 유지.
- `scripts/qa-learning.mjs`, `scripts/qa-layout.mjs`: 새 흐름과 재탐구·포커스·이탈 검증.

## 검증 방법

최종 결과: 모델 테스트 20개, 20개 의뢰 → 코어 복구 → 인증서 전체 여정, 재탐구·키보드·완료 직전 이탈, 프로덕션 빌드 통과. 선택형 개념 영상의 재생·길이·중간 장면도 확인했다.

1280×800, 906×755, 1920×1080, 1024×768, 1440×900, 873×580에서 초기 화면·의뢰 화면·설정·코어를 검사해 레이아웃 경고와 브라우저 오류가 없었다. 최종 조정한 작은 화면의 질문·결과 13개 상태도 패널 넘침 없이 통과했다. 브라우저의 터치 이벤트를 사용해 배송·조립·피스톤 조작과 오답 수정 경로를 별도로 확인했다.

`npm test`, `npm run build`, 실행 중인 로컬 서버에서 `npm run qa:browser`, `npm run qa:layout`을 사용한다. 브라우저 QA는 별도 Chrome 컨텍스트를 사용해 사용자의 학습 기록을 바꾸지 않는다.

`QA_WIDTH`, `QA_HEIGHT`로 전체 여정의 화면 크기를 지정할 수 있다. `QA_SKIP_VIDEO=1`은 영상 자체 검증이 끝난 뒤 조작 회귀 검사를 가볍게 반복할 때 사용한다. 기본 실행에서는 개념 영상의 디코딩·길이·중간 장면도 확인한다.

실제 태블릿 하드웨어, QR 인앱 브라우저, 외부 배포는 이번 로컬 검수 범위에 포함하지 않았다.
