# 개념 모션 영상 컷 시트

2026-10-22. ai-video-prompt 지침을 적용한 코드 기반 모션 그래픽. 각 9초, 3초씩 세 컷. 사람이 등장하지 않는 과학 도해이므로 인물 시트는 사용하지 않는다. 도해의 모양·색·기체 입자 수는 컷 간 유지하며, 기체를 넣고 빼는 무게 실험에서만 입자 수를 바꾼다. 입자는 기체의 양을 표현하는 모식도이고 실제 입자 크기나 간격을 재현한 것이 아니다.

모든 컷의 [CAMERA]: 정지 카메라 / 정면 도해 / 전체 장치가 보이는 미디엄 와이드 / 이동 속도 0. 종료 1초에는 핵심 결과를 같은 구도로 유지한다. 카메라 전환보다 조건 변화 자체에 집중한다.

| 영상 | 0–3초: 관찰 | 3–6초: 변화 | 6–9초: 결과와 종료 구도 |
|---|---|---|---|
| flow | 펌프·이어진 관·팬 | 공기가 관을 따라 이동 | 도착한 바람과 회전하는 팬 |
| weight | 같은 두 용기 비교 | 오른쪽에 공기만 추가 | 공기를 빼면 다시 무게가 줄어듦 |
| temperature | 밀폐된 공기와 온도 | 따뜻해지며 같은 양의 공기 부피 증가 | 차갑게 하여 부피 감소 |
| pressure | 밀폐 피스톤, 일정한 온도 | 피스톤이 내려가며 부피 감소 | 누르는 힘을 줄여 부피 회복 |
| nitrogen | 밀봉 과자 포장 | 질소로 둘러싸는 보호 도해 | 쉽게 반응하지 않는 성질과 포장 유지 |
| oxygen | 호흡 기관의 도식 | 공기에서 산소가 들어옴 | 호흡에 필요한 산소와 완만한 호흡 움직임 |
| carbon | 이산화탄소가 녹아 있는 음료 | 뚜껑이 열림 | 기포가 되어 빠져나옴 |
| extinguisher | 일부 소화기의 도식 | 이산화탄소 방출 | 불이 타는 것을 돕지 않는 성질 / 가상 도해 |
| engineering | 공급부·관·노즐 연결 | 밸브를 열고 공기 이동 | 목표 팬 회전 |
| car | 풍선 자동차, 출구가 뒤를 향함 | 공기가 뒤로 나감 | 자동차가 앞으로 이동 |

각 [SCENE]은 위 표의 고정 장치와 움직임을 사용한다. 청록·크림·황동 색을 기존 프로젝트 배경에서 가져와 일관성을 유지한다. 시각 도해 안에는 한글·영문·수치를 넣지 않는다. 앱의 DOM 자막이 0·3·6초에 해당 컷 설명으로 바뀐다. 관찰과 개념을 먼저 읽어주는 스포일러가 없도록 실제 발견을 저장한 뒤 영상이 열린다.

사운드: 무음 영상이며 게임 BGM을 일시 정지한다. 종료 확인음은 설정된 효과음 스위치를 따른다. 재생 실패 시 마지막 장면과 세 자막을 모두 제공한다. 일시정지·다시 보기·다음 활동은 사용자가 직접 선택한다.
