31~34번은 알파 채널이 있고 좌측 상단 픽셀이 투명이야. 캐릭터 포즈 모음은 한 장에 여러 포즈가 있으므로 실제 사용 전에 개별 포즈 분리, 가장자리 잘림, 외곽 여백을 확인해야 해. 여우 시트에는 화면 가장자리에 걸친 소품과 하단 표식이 있어. 원본의 외형과 표식은 현재 수정하지 않았어.

로고를 제외한 이미지 33장은 모두 1672×941이야. 이미지 크기와 파일 용량은 `image-metadata.json`에 기록했어.

## 새로 필요한 핵심 자료

1. 자연형 2.5D 픽셀 선택 지도와 분리된 입구·전경·길 레이어.
2. 지도용 학생 아바타의 방향별 대기·걷기 프레임.
3. 파이프·밸브·노즐·저울 등 독립 조작 오브젝트와 상태 이미지.
4. 복구 전후의 지도 시설 상태 및 코어 작동 상태.
5. UI에 가려지지 않는 NPC 단독 포즈.
6. 효과음과 배경음. 기존 폴더에 오디오는 없으므로 구현 때 별도 확보해야 해.

3D 이미지 제작 목록과 프롬프트는 [별도 문서](../planning/3D-ASSET-PROMPTS.md)에 있어. 현재 이미지 생성, 배경 편집, 캐릭터 분할은 수행하지 않았어.
