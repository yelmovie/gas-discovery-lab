# 기체 도시 대작전 장별 시나리오 논의안

상태: 설계 확정 전 대화용 초안 · 2026-10-14

공유 대화 링크는 본문에 접근하지 못했어. 아래는 전달된 `gas-city-operation_deep-design_v2.md`, 이미지 34장, 이번 요청을 기준으로 정리했어. 공유 대화에서만 합의한 내용은 아직 반영 여부를 확인할 수 없어.

## 이번 요청에서 확정된 화면 원칙

- 메인 화면 다음에 자연형 스테이지 선택 지도에 들어가.
- 지도만 위에서 비스듬히 보는 2.5D 픽셀 RPG야. 캐릭터가 길을 따라 걸어 시설 입구에 도착해.
- 각 시설에 들어가면 기존 시안의 청록·흰색·황동색을 살린 2D 실험/활동 화면으로 전환해. 실내까지 픽셀 RPG로 통일하지 않아.
- 모든 페이지 왼쪽 위에는 홈·이전, 오른쪽 위에는 소리·설정을 둬.
- 설정의 `관리자 전체 해금` 한 번으로 모든 장과 화면을 열어. 장별·섹션별 해금 선택은 두지 않아.
- 이번 단계에서는 시나리오를 먼저 이야기하고, PRD/TRD는 확정 전 초안으로 남겨.

## 전체 이야기

학생은 에어 엔지니어가 되어 멈춘 기체 도시의 공기 코어를 복구해. 각 장에서 직접 조작하고 관찰한 결과를 연구 가방에 담아. 마지막에는 그 기록과 자신이 만든 장치를 이용해 코어를 직접 다시 움직여.

지도 배경은 **숲·강·언덕 속에 기체 도시의 연구시설 다섯 곳을 배치하는 자연형 연구 마을**로 확정했어. 자연형 2.5D 픽셀 지도와 기존 미래형 2D 실내 배경을 연결해. 중앙 관제 본부는 마지막 복구 장소로 별도 배치하는 안을 유지해.

```text
메인 → 짧은 사건 소개 → 자연형 2.5D 선택 지도
  → 시설 입장 → 2D 탐구 → 증거 획득 → 지도에서 복구 결과 확인
  → 5개 장 완료 → 관제 본부 → 보고 → 직접 복구 조작 → 엔딩
```

## 장별 시나리오

| 구간 | 사건과 학생의 행동 | 남기는 증거와 변화 |
|---|---|---|
| 도입 | 중앙 공기 코어가 멈춰. 여우 발명가 에어가 고장 원인을 확인해 달라고 의뢰해. 지도에서 첫 시설까지 걸어가. | 연구 가방을 받고 첫 탐구 목적을 알아. |
| 1장 끊어진 공기 동력선 | 외곽 동력선의 연결이 끊겼어. 2D 장면에서 고장 부위를 찾고 관을 연결한 뒤, 공기를 보내 팬이 움직이는지 관찰해. 연결을 바꾸며 다시 시험해. | 연결 경로와 작동 전후가 담긴 **공기 흐름 기록**. 지도에서 첫 파이프와 소형 장치가 켜져. |
| 2장 보이지 않는 무게의 증거 | 물류 계측기가 이상한 값을 보여. 고양이 연구원 루미와 저울의 수평·영점을 확인하고, 같은 단단한 용기에 공기를 더 넣기 전후를 측정해. 기록 중 비교 가능한 두 개를 골라 결론을 만들어. | 조건과 두 측정값을 담은 **기체 무게 측정 기록**. 계측실과 운송 장치가 다시 움직여. |
| 3장 변하는 부피의 규칙 | 온도·압력 장치의 기록이 사라졌어. 온도에 따라 유연한 막의 크기가 변하는 모습을 관찰하고, 피스톤과 감압 장치로 압력에 따른 부피 변화도 비교해. 산의 과자 봉지와 물속 공기방울 사례에 적용해. | 온도·압력 전후 비교를 담은 **부피 변화 환경 기록**. 지도에서 환경 관측소가 켜져. |
| 4장 도시 기체 관제 | 시설마다 필요한 기체를 찾지 못해 멈췄어. 다람쥐 관제원 포포에게 시설 요청을 받고 질소·산소·이산화탄소의 성질과 이용을 조사해. 알맞은 공급을 선택하고 근거를 붙인 뒤 시설 반응을 확인해. | 시설 요청·선택·이유가 담긴 **기체 관제 보고서**. 포장·호흡 지원·탄산음료 시설이 복구돼. 헬륨은 선택 확장이야. |
| 5장 공기 복구 장치 설계 | 중앙 코어를 다시 움직일 장치를 만들어야 해. 공기 공급부·관·밸브·노즐을 2D 작업대에서 조립하고 시험해. 누수와 방향을 확인해 수정하며, 목표를 만족하는 여러 연결을 허용해. | 실제 부품 배치와 시험 결과를 담은 **공기 장치 설계도**. 코어 연결 포트가 열려. |
| 마지막 관제 본부 | 포포에게 실제 증거 5개를 제출해. 만든 장치를 연결하고 밸브를 조작해 공기를 공급한 뒤 복구 레버를 당겨. | 코어가 돌아가고 도시가 완전히 복구돼. 짧은 엔딩 뒤 연구 기록과 인증서를 열어. |

## 기존 10개 핵심 활동 화면의 배치

메인·선택 지도는 아래 10개 활동 화면과 별도야. 5장은 5개의 학습 미션이며, 화면 수와 같지 않아.

| 장 | 화면 | 이번 요청을 적용한 표현 |
|---|---|---|
| 1 | S01 고장 지점 조사 / S02 공기 흐름 시험 | 고정 2D 장면의 핫스팟과 관 연결, 작동 전후 기록 |
| 2 | S03 무게 계측 / S04 증거 분석 | 2D 저울 조작, 실제 측정 기록 비교 |
| 3 | S05 온도 터널 / S06 압력과 생활 사례 | 2D 연속 변화, 온도와 압력 실험을 구분해 비교 |
| 4 | S07 기체 정보 조사 / S08 기체 배달 관제 | 시설 요청에서 출발해 조사하고 공급하는 2D 활동 |
| 5 | S09 장치 조립과 시험 | 2D 부품 연결과 시험. 3D 확대 보기는 후속 선택안 |
| 최종 | S10 관제 본부 | 보고 → 장치 연결과 복구 → 엔딩 → 완료의 네 상태 |

## 흥미와 몰입을 높이는 제안

1. **실험 결과가 지도에 남아.** 장을 끝내면 해당 건물과 파이프가 실제로 켜지고, 다시 방문해도 복구된 모습이 유지돼.
2. **오류가 다음 행동을 알려줘.** 연결이 잘못되면 공기 경로가 끊긴 곳을 보여주고, 비교 조건이 다르면 해당 조건을 강조해. 틀렸다는 표시만 띄우지 않아.
3. **연구 가방이 마지막 문제를 푸는 도구가 돼.** 일반 보상 카드 대신 내가 남긴 측정값·비교 장면·설계도를 다시 사용해.
4. **NPC가 역할에 맞게 도와줘.** 에어는 연결과 제작, 루미는 조건과 비교, 포포는 시설 요청과 증거 관리를 맡아.
5. **다른 방법으로 성공할 수 있어.** 5장에 최소 두 개의 유효한 연결 경로를 두고, 재시도를 벌점으로 만들지 않아. 선택 탐구와 대체 장치는 후속 확장으로 둬.

맵 이동 자체가 숙제가 되지 않게 입구 간 거리는 짧게 두고, 방문한 시설에는 빠른 이동도 제안해. 점수·상점·전투·꾸미기는 현재 범위에 추가하지 않아.

## 3D 적용 판단

- MVP의 모든 실내 화면은 2D로 유지해. 입체 렌더 느낌의 배경·오브젝트를 사용하는 것과 실제 3D 조작은 구분해.
- 가장 유용한 후속 후보는 **S09 장치 연결부를 돌려 확인하는 작은 확대 보기**야. 연결 방향을 이해하는 데 도움이 있을 때만 넣어.
- S10 코어는 3D로 미리 렌더한 작동 이미지나 2D 레이어 애니메이션만으로도 충분해.
- S06 산·바다 사례는 2D 높이·깊이 이동으로 구현할 수 있어. 실제 3D는 우선순위가 낮아.
- 저울·증거 분석·정보 카드는 수치와 비교가 핵심이라 2D가 적합해.
- 2.5D 선택 지도는 픽셀 타일·스프라이트·앞뒤 가림으로 표현할 수 있어. 실제 3D 지형을 필수로 두지 않아.

## 협의가 필요한 부분

- 지도에서 조작할 학생 아바타의 외형. 기존 세 캐릭터는 담당 NPC로 유지하는 안이야.
- 한 번의 수업에서 전체를 마칠지, 장별로 나누어 사용할지. 예상 시간과 실험량은 이에 맞춰 조정해야 해.
- 공유 대화에서 추가로 결정한 내용이 있는지.

## 과학 표현에서 바로잡을 부분

- 온도 실험에서는 기체의 양을 유지하고 부피가 변할 수 있는 유연한 막을 사용해. 단단한 밀폐 용기의 겉크기가 변하는 그림은 쓰지 않아.
- 압력 실험에서는 기체의 양과 온도 조건을 유지하는 비교로 설계해. 입자 모형이나 공식으로 원인을 설명하지 않아.
- 무게 실험은 같은 단단한 용기를 같은 조건에서 비교해. 표시값은 가상 실험값임을 안내하고, 아직 임의 수치를 확정하지 않아.
- 공기 흐름의 빛·화살표는 이동 경로 안내이고 실제 공기의 색이나 입자 그림이 아니야.
- 배관 퍼즐의 밸브 조건은 장치 구조로 설명할 수 있어야 해. 근거 없는 순서 암기를 성공 조건으로 두지 않아.
