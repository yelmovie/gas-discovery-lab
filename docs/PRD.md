# 기체 도시 대작전 PRD 초안

상태: 시나리오 협의 중 요구사항 정리 · 2026-10-14

현재 요청과 제공 자료에서 확인한 요구사항을 기록했어. 구현과 화면 구성을 최종 확정한 문서는 아니야. 자세한 이야기는 [시나리오 논의안](planning/SCENARIO.md)을 기준으로 이야기하면 돼.

## 목적과 대상

초등학생이 공기의 무게, 온도·압력에 따른 부피 변화, 여러 기체의 성질과 이용을 직접 관찰하고 장치 설계에 적용하는 가로형 태블릿 과학 게임이야. 제공 문서는 초등 4학년 과학을 대상으로 하며, 성취기준 문장은 경기도교육청 「초등 깊이있는 수업 프레임워크 부록」 인쇄 77쪽의 [4과15-01]~[4과15-04]와 2026-11-08에 대조했어. 부피가 같은 용기의 무게 비교, 온도·압력에 따른 부피의 정성적 관찰을 중심으로 하고 입자 모형으로 원인을 설명하지 않아. 교육부 원본 ZIP 재검증이나 실제 학습 효과 인증을 뜻하지는 않아.

확인 자료: https://www.goe.go.kr/resource/old/BBSMSTR_000000030136/BBS_202411110127574203.pdf

## 확정 요구사항

| ID | 요구사항 |
|---|---|
| R01 | 메인 다음의 선택 지도는 숲·강·언덕 속에 연구시설 5곳을 배치한 자연형 마을로 확정. 이 지도만 위에서 사선으로 보는 2.5D 픽셀 RPG로 표현 |
| R02 | 지도에서 캐릭터 이동과 시설 입장 제공 |
| R03 | 시설 안에서는 기존 이미지 스타일의 2D 활동 제공 |
| R04 | 모든 페이지 왼쪽 위 홈·이전, 오른쪽 위 소리·설정 제공 |
| R05 | 설정에 관리자 전체 해금 하나 제공. 장별·섹션별 선택 없음 |
| R06 | 자료와 에셋을 검토하고 원본을 보존해 폴더 정리 |
| R07 | 설계 확정 전에 장별 시나리오 협의 |
| R08 | 3D 활용 후보와 기본 이미지 프롬프트를 별도 문서로 제공 |

## 제안하는 MVP 범위

- 메인, 사건 소개, 선택 지도, 5개 미션의 10개 핵심 활동 화면, 최종 완료 흐름.
- 연결 → 작동 확인, 측정 → 기록 비교, 조건 변경 → 부피 비교, 조사 → 기체 공급, 조립 → 시험 → 수정.
- 실제 행동에서 생성된 연구 증거 5종, 지도 복구 상태, 로컬 저장과 이어하기.
- 최종 단계는 증거 제출과 장치 복구 조작을 완료해야 정상 완료 처리.
- 완료 화면의 연구 기록 보기와 간단한 인쇄용 인증서. 이름은 출력 시 선택 입력.

실시간 3D 실내 탐색, 온라인 계정, 서버 저장, 리더보드, 전투, 상점, 생성형 영상, 추가 보너스 퀘스트는 MVP 확정 범위에 포함하지 않았어.

## 공통 UI의 동작 제안

- 홈은 메인으로 이동해. 이전은 활동 안에서는 직전 화면, 장 첫 화면에서는 선택 지도로 돌아가.
- 메인에서도 네 아이콘의 위치를 유지해. 홈·이전은 비활성 상태와 이유를 표시해.
- 소리는 전체 음소거 상태를 전역 적용하고 저장해. 설정의 같은 값과 동기화해.
- 설정은 모든 페이지에서 같은 모달을 열어. 배경 조작을 막고 닫으면 원래 위치로 돌아가.
- 관리자 전체 해금은 모든 장·활동·최종 화면의 접근 잠금을 한 번에 풀어. 실제 수행 기록이나 인증서 완료를 위조하지 않아.
- 미완료 화면을 미리 볼 때 필요한 예시 데이터는 미리보기 상태로 분리해. 빈 기록 때문에 관리자 접근이 막히지 않게 해.
- 전체 해금을 해제해도 실제 학습 진행과 기록은 보존해. 이 동작은 구현 시 확정할 제안이야.

## 수용 기준 초안

1. 지도에서 캐릭터로 시설에 접근하고 입장하면 2D 장면으로 전환돼.
2. 모든 화면과 최종 완료 화면에서 공통 아이콘을 사용할 수 있어.
3. 전체 해금 한 번으로 모든 화면에 접근하며, 섹션 선택이나 완료 기록 조작이 없어.
4. 각 미션은 조작 결과를 관찰하고 기록해야 완료돼. 다음 버튼 클릭만으로 증거를 주지 않아.
5. 잘못된 연결·측정 조건에서 원인을 확인하고 같은 활동을 다시 시도할 수 있어.
6. 5장의 서로 다른 유효한 연결이 성공하며, 누수·방향 오류는 관찰 가능한 결과로 드러나.
7. 실제 증거 5개와 직접 복구 조작 없이 정상 인증서 완료로 처리하지 않아.
8. 새로고침 후 기록·설정·현재 진행을 복원해.
9. 1280×800과 1024×768 가로 화면에서 핵심 조작과 공통 아이콘이 잘리지 않아.
10. 드래그 활동에는 선택 후 배치 방식도 제공하고, 주요 터치 영역은 48px 이상을 목표로 해.

지도 배경은 자연형 연구 마을로 확정했어. 수업 시간, 학생 아바타, 시설의 세부 배치, 최종 실험값은 협의 후 확정해.
