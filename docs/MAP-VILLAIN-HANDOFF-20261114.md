## 외형과 등장

**바람길 잠금 풍선 봇 / 빨간 풍선, 두 장갑으로 접은 파란 공기 관.** 스테이지 완료 기록 후 지도에 돌아올 때 해당 장소 옆에 등장한다. 기존 주인공·동료·건물의 스타일을 유지하고, 악당과 소품의 접점이 글 없이도 읽히게 그린다. 아래 소품 동작은 지도 위 짧은 장난 컷이다. 활동 화면이나 기존 학습 데이터에는 손대지 않는다.

풍차는 공기 흐름을 보이는 소품. 수업의 배관·압력 실험과 연결 입력을 요구하지 않는다.

## 스테이지마다 바뀌는 소품·자세·대사

장소명은 기획상의 연결 기준이다. 활성 버전의 스테이지 ID와 이름을 대조한 뒤 키를 정한다. 선택 구역은 실제 별도 완료 이벤트가 있을 때만 추가한다.

| 장소 | 악당 스프라이트 동작 | 첫 등장 또는 접근 대사 예시 |
|---|---|---|
| 바람 동력소 | 파란 관을 접어 환기팬 멈추기 | “팬은 이제 바람 못 받지!” |
| 무게 연구소 | 저울 한쪽 접시에 모형 추를 얹기 | “접시가 한쪽만 내려가네!” |
| 환경 관측소 | 피스톤 손잡이를 눌렀다 올리기 | “이 손잡이가 마음에 드는데?” |
| 기체 배송소 | 배송 캡슐 모형을 관 앞에서 잡기 | “이 캡슐은 못 지나가!” |
| 공기 공작소 | 노즐을 옆으로 돌려 풍차를 빗나가게 하기 | “바람을 이쪽으로 돌려야지!” |

상황 대사 예시:

- 접근: “이 관은 내가 꾹 접었어!” / “바람은 여기서 멈춰!”
- 1·2타: “앗, 풍선이 움푹했어!” / “내 노즐이 휙 돌아갔잖아!”
- 퇴장: “피슈우… 바람 빠진다!” / “관은 이제 놓을게!”

스테이지 고유 문장을 우선하고, 상황 대사는 연속 반복 없이 고른다. 주인공·보조 캐릭터의 주민 대화와 겹칠 때는 악당 말풍선을 생략한다.

## 세 번의 타격과 접촉 피격

| 사건 | 이 프로젝트의 표현 |
|---|---|
| 1타 · 짧은 명중 | 한 겹 공기 고리가 퐁 |
| 2타 · 더 큰 반동 | 풍선이 찌그러지고 짧은 바람 리본이 두 방향 |
| 3타 · 마무리와 퇴장 | 노즐로 바람이 빠지며 작아져 ‘피슈우’ 퇴장 |
| 주인공 접촉 | 주인공은 바람에 상체가 눕고 발로 버팀 |
| 보조 캐릭터 접촉 | 동료는 볼이 흔들리며 짧게 들렸다 착지 |
| 악당의 접촉 공격 동작 | 풍선이 작게 부풀었다 노즐에서 반투명 바람 고리 한 번. 그 프레임에서만 접촉 표시. |
| 타격·퇴장 효과음의 차이 | 퐁 → 푹 → 피슈우 |
| 접촉 효과음 모티프 | ‘퐁, 피슈우’ |

세 타격은 같은 공격 입력이다. 가까이 있는 상태에서 한 입력이 한 타로 계산된다. 접촉 피격은 닿은 쪽만 재생하고 공격 카운트와 학습 진행에는 영향을 주지 않는 것을 권장한다. 소리를 꺼도 표정·자세·게이지로 읽혀야 한다.

## 방향과 시선

[공통 방향 규칙](../../_shared/MAP-VILLAINS-HANDOFF-20261114.md#방향시선공격-자세)을 적용한다. 노즐과 팔은 상대 쪽으로 돌아서되, 막힌 관과 멈춘 바람개비를 함께 뒤집지 않는다. 접촉 이펙트는 해당 방향 노즐 끝에서 시작한다.

## 제작하고 적용할 순서

1. 기존 진입점 확인: [src/data.js](../src/data.js) · [src/map.js](../src/map.js) · [src/map-sprite.js](../src/map-sprite.js). 활성 지도와 완료 상태, 실제 주인공/보조 지도 원본·이름, 기존 악당/스프라이트·대사·저장부터 확인한다.
2. 기본 악당 한 장, 위 표의 장소별 소품 동작 스트립, 공통 이동/접촉 전조/피격/퇴장 프레임을 제작한다. 주인공·보조 피격은 각각 4~6프레임. 소품이나 배경을 몸통 시트에 같이 구워 넣기 전에 지도 크기에서 알아볼 수 있는지 확인한다.
3. 별도 승인된 구현 단계에서 완료된 장소 좌표에 악당을 붙이고, 기존 HUD 근처에서 공격·타격·피격·퇴장만 연결한다. 기존 이동/화면 전환/복구 상태와 학습 완료/다음 장소 해금은 보존한다.
4. 완료 전/후, 정확한 3타, 두 아군의 개별 접촉, 퇴장 및 재진입, 빠른 연타, 무음·모션 감소·태블릿을 확인한다. 가장 작은 정상 지도 표시 크기에서 소품과 방해 동작이 구분되는지 본다.

완료된 것: 정적 이미지 합성과 계획. 남은 것: 기존 시트/캐릭터 일치 확인, 프레임 제작, 대사 최종화, 구현 및 테스트. 06 물의 상태 변화는 참고 전용.
