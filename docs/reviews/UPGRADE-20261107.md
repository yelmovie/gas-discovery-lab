# 15 기체 도시 대작전 개선 기록

2026-11-07. 1~5 완성본은 수정하지 않음. 사용자의 15번 명시 추가 승인 후 작업. 기존 미커밋 변경을 유지했으며 커밋/배포/원본 삭제 없음.

## 적용
- 교사 시연을 학생 저장의 메모리 복사본으로 분리. 시연 실험·초안·배지는 저장하지 않으며 종료하면 학생 원상태 복원. 저장된 과거 전체해금 값으로 시연 자동 재개하지 않음.
- 재도전의 최신 관찰과 최초 관찰을 함께 보존. 연구 가방에서 첫 탐구 내용을 확인 가능. 이전 버전에서 이미 덮어쓴 기록을 복원한 것은 아님.
- 깨진 저장은 자동 덮어쓰기하지 않음. 명시 초기화도 기존 데이터의 복구 사본 쓰기가 성공해야 진행. 실패 시 메모리 기록 유지.
- 다른 탭에서 바뀐 저장을 감지하면 덮어쓰기를 중단하고 내보내기/새로고침 안내. 원자적 다중 탭 트랜잭션은 아니므로 정확히 동시 저장하는 경쟁 상황은 남을 수 있음.
- 저장 실패/시연 상태를 화면에 표시. 교사 모드 전환 시 진행 중 활동 취소 후 지도로 이동해 이전 콜백 혼합 방지.
- 부피 실험의 통제변인: 온도 실험은 같은 양·바깥 압력, 압력 실험은 같은 양·온도를 명시.
- 873×580 단계 소개 패널 14px 세로 넘침을 간격 조정으로 해결. 버튼 크기는 줄이지 않음.

## 학습·중복 점검
4과15-01~04와 코드에 연결된 20개 활동 확인. 바람길 연결 → 같은 용기 무게 비교 → 온도/압력 부피 비교와 전이 → 기체 성질을 근거로 배송 → 부품 선택/방향/밸브 시험으로 서로 다른 조작을 사용한다.
시설 안의 4개 의뢰는 동일 조작을 반복하는 부분이 있다. 특히 무게 3·4차시와 바람길 변형은 심화 폭이 크지 않으므로 교사가 조건 선택 이유를 질문하는 보조 수업으로 사용 권장. 실제 학습효과·재미를 학생 실험으로 입증한 것은 아니다.
기존 1~5 기준(최초/수정 증거 분리, 실험 조건 비교, 쉬운 조작/피드백)을 적용했으며 별도 운영시트 재조회는 하지 않았다. 기존 부모 점검 결과를 참고했다.

## 이미지·소리
기존 자체 생성 실험 그림·지도·캐릭터·개념 영상과 Kenney CC0 효과음이 충분해 재생성하지 않음. 새로운 모모 음성 생성/자원 사용 없음. 효과음과 배경음 개별 설정 유지. 따라서 신규 생성 임시파일도 없음.

## 개선 프롬프트(이번 적용 기준)
기존 코드와 자산을 보존하고, 교사 전체 해금을 학생 저장과 분리된 임시 시연으로 전환한다. 학생 초안·배지·최초 관찰을 보존하고 재도전 최근 증거를 함께 표시한다. 손상 저장과 다른 탭 최신 저장은 자동 덮어쓰기하지 않는다. 명시 초기화는 복구 사본을 먼저 만들고 실패하면 원상태를 유지한다. 상태 모듈 테스트를 먼저 실패시킨 뒤 구현하고 실제 설정 UI 및 20미션 흐름을 검증한다. 온도·압력 실험 통제변인을 명시하고 낮은 태블릿 화면의 소개 패널 넘침을 글씨/터치영역 축소 없이 해소한다. 기존 이미지·음향이 충분하면 새로 만들지 않는다.
