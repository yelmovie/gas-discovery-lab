# 2026-11-23 로컬 수정의 저장 호환

이 문서는 공개판 최종 검수 후 요청된 로컬 수정의 동작을 설명합니다. 공개 운영판 배포 기록이나 교사 과학 검수 완료 기록이 아닙니다.

## 최초 코어 완료일

- 기존 저장 키 `gas-city-adventure-v1`, `version: 1`, 의뢰·배지·공방 저장은 유지합니다.
- 새 필드 `finaleCompletedAt`은 최초 코어 복구 레버를 당긴 시각의 UTC ISO 문자열입니다. 모든 학생 의뢰를 마친 상태에서만 기록하며, 교사 시연에서는 기록하지 않습니다.
- 새 저장과 초기화 후에는 `null`입니다. 의뢰 재도전, 인증서 역량 선택, 새로고침, 코어 재입장·재복구는 이미 저장된 최초 시각을 바꾸지 않습니다.
- 인증서의 「모험을 마친 날」은 이 시각을 브라우저의 현지 날짜로 표시합니다. 화면·PDF·PNG는 같은 인증서 DOM을 사용합니다. 의뢰 증거의 마지막 날짜를 완료일로 사용하지 않습니다.
- `finaleCompleted: true`이지만 필드가 없는 예전 저장, 형식이 틀렸거나 존재하지 않는 날짜는 `null`로 읽고 「날짜 기록 없음」으로 표시합니다. 탐구 증거와 인증서 이용 권한은 보존합니다. 이미 완료한 예전 저장에서 코어를 다시 복구해도 그 시각을 원래 완료일로 채우지 않습니다.
- 미완료 저장의 완료 시각은 버립니다. 문자열은 `Date#toISOString()`으로 동일하게 되돌릴 수 있는 밀리초 단위 UTC 형식만 인정합니다.
- 초기화는 기존 저장 전체를 `gas-city-adventure-v1-recovery`에 보관한 뒤 새 진행과 `null` 날짜로 시작합니다. 기록 보관 실패나 다른 탭의 충돌 처리 방식은 유지합니다.

## 산악 관측소 초안

- 기존 `condition`, `records`, `prediction`, `misses`에 선택적 `checkpoint`를 추가했습니다. 0은 생략할 수 있고, 유효한 정수 0~3만 복원합니다.
- 안전 지점 도달 시에만 저장합니다. 매 프레임 위치, 점프 중 위치, 낙하 위치는 저장하지 않습니다. 새로고침은 해당 안전 지점에서 재개합니다.
- 예상이 없는 기록 전 초안이나 잘못된 번호는 출발 지점으로 처리합니다. 예전 초안에 번호가 없으면 출발 지점이며, 이미 두 관측 기록이 있으면 비교 화면에서 이어갑니다.
- 체크포인트 복원은 관찰 기록이나 완료 증거를 생성하지 않습니다. 정상 관측 지점의 「기록」을 직접 누르고 전이 질문에 답해야 완료됩니다.
- 2D 대체 화면은 선택한 관측 지점 `station`을 추가로 보관합니다. 지점 이동·새로고침만으로 완료되지 않습니다. 3D와 2D는 `mountain-rules.js`의 같은 모형값·관찰·완료 판정을 쓰고, 전환 시 예상·기록·오답 횟수를 넘깁니다.
