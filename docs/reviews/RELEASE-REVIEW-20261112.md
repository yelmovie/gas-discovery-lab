## 해결한 주요 문제

1. 공방의 긴 조작 뒤 키보드 포커스와 스크롤 위치가 돌아가는 문제를 수정했다. 공기 빼기 결과를 즉시 저장하고 손상 기록·다른 창의 최신 기록·저장 공간 부족에 대한 보호를 추가했다.
2. 낮은 가로 화면의 시작 UI와 공방 조작을 재배치했다. 좁은 화면에서 완료 후 다음 버튼이 지나치게 줄어드는 문제와 다음 조작 버튼의 낮은 대비를 수정했다.
3. 공개 서버가 영상 Range 요청에 전체 파일을 반환해 장면 이동이 0초로 돌아가는 문제를 재현했다. 짧은 개념 영상을 Blob URL로 재생하고 종료 시 해제하도록 수정했다. CSP의 미디어 허용 범위도 함께 적용했다. [Cloudflare 정적 에셋 제한](https://developers.cloudflare.com/workers/static-assets/billing-and-limitations/)
4. 풍선 자동차의 정답 조건에 풍선 공급부를 명시했다. 기체 배송은 기체를 바꾼 뒤 이유를 다시 고르게 하고, 저장된 정답 초안도 학생의 확인 입력을 거치도록 수정했다.
5. 부피 실험의 일정 조건, 부피·성질·설계의 뜻, 공급부·노즐·밸브의 쉬운 설명, 무게 실험의 현재 행동을 보완했다. 다음 시설에서 탐구할 내용을 완료 안내와 연결했다.
6. 공방의 공기 주머니와 나무 상자를 각각 생성해 적용했다. 상자가 받침에 닿은 채 함께 이동하도록 확인했다. 두 사용본은 총 44,778바이트다.
7. 830×515에서 기록이 쌓인 마지막 무게 실험의 안내가 결과 영역을 밀어내는 문제를 발견해 문장을 줄였다. 최종 970개 상태 검사에서 해당 문제를 포함한 화면 이슈 0건을 확인했다.

8. 실제 버튼뿐 아니라 `role="button"`으로 구현된 용기와 모든 끌기 대상까지 검사했다. 슬라이더 높이를 48px로 넓히고 저울 옆 용기의 터치 경계가 패널 안에 들어오도록 조정했다.
