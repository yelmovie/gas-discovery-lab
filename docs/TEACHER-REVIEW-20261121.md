|---|---|---|---|---|---|---|
| 멈춘 환기팬을 돌려요 | 관을 돌려 공기 길을 이어요. | 관 9칸 돌리기(패턴 0) | 입구~팬이 이어짐 | 공기가 관을 따라 이동해 팬을 밀었어요. | | 확인 필요: 성취기준 4개 중 직접 대응하는 것이 없다(4과15-04 장치 설계의 준비 활동으로 보임). 연결 근거 확인 |

## 2. 무게 연구소 — 보이지 않는 무게 ([4과15-01])

- 개념 문장: 「공기에도 무게가 있을까요? 같은 용기에서 공기의 양만 바꾸어 비교해요.」
- 핵심어: 무게, 같은 용기, 공기의 양, 0점, 수평
- 안내·오답 피드백:
  - 「수평계의 방울이 가운데에 왔어요.」
  - 「용기를 내린 빈 저울에서 0점을 맞춰요.」
  - 「먼저 용기를 저울에 올려 주세요.」
  - 「같은 무게는 이미 기록했어요. 공기의 양을 바꿔 보아요.」
  - 「처음 기록을 남겼어요. 이제 공기의 양만 바꾸어 다시 재어요.」

| 의뢰 | 학습 목표 | 문항·조작 | 정답(완료 조건) | 결과 설명 | 맞음 / 고칠 것 | 메모 |
|---|---|---|---|---|---|---|
| 공기를 더 넣으면 어떨까요? | 빈 저울을 맞춘 뒤, 공기를 넣기 전후를 재요. | 수평·0점 → 용기 올리기 → 공기 넣기(1칸 이상) → 기록 | 넣은 뒤 무게가 늘어난 기록 | (결과 카드: 처음과 나중 무게 비교) | | 확인 필요: 화면 값은 소수 둘째 자리 g(예: 150.48 g)다. 실제 공기 1칸의 무게 차이가 이 정도인지, 「모형 저울」이라는 표시로 충분한지 |
| 공기를 빼면 어떨까요? | 맞춰 둔 저울 그대로, 공기를 빼고 다시 재요. | 공기 빼기(1칸 이상) → 기록 | 줄어든 기록 | | | |
| 저울 조건부터 바르게 맞춰요 | 저울을 바르게 맞추고, 비교할 수 있는 기록을 만들어요. | 수평·0점 → 넣기 2칸 이상 | 늘어난 기록 | | | |
| 한 번 더 재도 같을까요? | 맞춰 둔 저울로 공기를 2칸 이상 빼고 다시 확인해요. | 빼기 2칸 이상 | 줄어든 기록 | | | |

## 4. 기체 배송소 — 알맞은 기체를 찾아요 ([4과15-03])

- 개념 문장: 「성질은 물질이 가진 특징이에요. 기체의 성질을 조사해 알맞은 쓰임을 찾아요.」
- 기체 카드(`GASES`):
  - 질소 N₂: 「다른 물질과 쉽게 반응하지 않아요.」 「과자 봉지 등 식품 포장에 이용돼요.」
  - 산소 O₂: 「사람의 호흡에 필요해요.」 「불이 타는 것을 도와요.」
  - 이산화 탄소 CO₂: 「물에 녹아 탄산음료를 만들어요.」 「불이 타는 것을 돕지 않아요.」
  - 카드 아래 안내: 「카드의 색은 구분용 표시예요.」
- 오답 피드백: 기체가 틀리면 「성질과 쓰임을 살펴보고 기체를 바꿔요.」, 이유가 틀리면 「조사한 성질과 비교해서 이유를 다시 골라요.」

| 의뢰 | 학습 목표 | 문항 | 정답 기체 | 정답 이유 | 결과 설명 | 맞음 / 고칠 것 | 메모 |
|---|---|---|---|---|---|---|---|
| 과자 포장실의 부탁 | 과자가 쉽게 변하지 않도록 도와줄 기체를 찾아요. | 기체 1개 + 이유 1개 고르기 | 질소 | 다른 물질과 쉽게 반응하지 않아요. | 질소는 다른 물질과 쉽게 반응하지 않는 성질을 이용해 식품 포장에 쓰여요. | | 정답 카드·이유가 모두 첫 자리(A8, 3-2단계에서 순서 섞기 예정) |
| 호흡 지원실의 부탁 | 숨 쉬기를 돕는 장치에 넣을 기체를 보내 주세요. | 같음 | 산소 | 사람의 호흡에 필요해요. | 산소는 사람의 호흡에 필요한 기체예요. 이곳은 성질과 이용을 살피는 가상 시설이에요. | | |
| 탄산음료 공방의 부탁 | 톡 쏘는 탄산음료의 기포를 만들 기체를 찾아요. | 같음 | 이산화 탄소 | 물에 녹아 탄산음료를 만들어요. | 이산화 탄소가 물에 녹아 있는 탄산음료에서는 뚜껑을 열 때 기포를 볼 수 있어요. | | |
| 안전 시설의 마지막 부탁 | 일부 소화기에 쓰이는 기체와 성질을 찾아요. | 같음 | 이산화 탄소 | 불이 타는 것을 돕지 않아요. | 이산화 탄소는 불이 타는 것을 돕지 않아 일부 소화기에 이용돼요. 실제 소화기 사용 실험은 하지 않아요. | | 정답 이유가 첫 자리(A8) |

## 5. 공기 공작소 — 나만의 복구 장치 ([4과15-04])

- 개념 문장: 「설계는 부품과 연결 방법을 정하는 일이에요. 공기로 움직이는 장치를 만들고 고쳐요.」
- 오답 피드백:
  - 「부품과 연결 칸의 이름을 맞춰 주세요.」
  - 「공급부·관·노즐을 먼저 모두 연결해요.」

| 의뢰 | 학습 목표 | 문항·조작 | 정답(완료 조건) | 결과 설명 | 맞음 / 고칠 것 | 메모 |
|---|---|---|---|---|---|---|
| 공기로 작은 팬을 돌려요 | 공급부 → 관 → 노즐을 연결해 팬에 공기를 보내요. | 부품 3개 고르기 → 밸브 | 손 펌프 + 일자 관 + 노즐(앞) | 공기를 모아 관으로 보내면 팬을 움직일 수 있어요. | | |
| 다른 길로 풍차를 돌려요 | 굽은 관을 써서 공기를 풍차까지 보내요. | 같음 | 굽은 관 필수 | 공기 길은 여러 모양으로 만들 수 있어요. 연결과 방향이 중요해요. | | |
| 풍선 자동차가 나아가게 해요 | 풍선에 모은 공기를 뒤로 내보내는 장치를 설계해요. | 같음 + 방향 | 풍선 공급부 + 노즐 뒤로 | 공기가 뒤로 나가면서 풍선 자동차가 앞으로 움직여요. | | |
| 중앙 코어의 복구 장치 | 공기를 코어 쪽으로 보내는 장치를 완성해요. | 같음 | 노즐 앞 | 공기의 이동을 이용한 내 장치로 중앙 코어를 다시 움직일 수 있어요. | | |
