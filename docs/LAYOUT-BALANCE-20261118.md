# 놀이 화면 비율·중복 조작 버튼 정리 (2026-11-18 밤 ~ 11-19)

기준: `_shared/LAYOUT-BALANCE-DELIVERY-20261118.md` 1·2절. 측정 스크립트는 `.tmp/layout-balance-20261118/measure.mjs`, 수정 전·후 스크린샷과 `measure.json`은 같은 폴더의 `before/`·`after/`에 있다(세 뷰포트 1280×800, 1024×768, 1920×1080).

## 측정 방법

- 화면마다 두 값을 잰다. **카드**는 학생이 읽고 누르는 패널 하나다. **장면 묶음**은 이 프로젝트의 고유 배치인 「인물 + 카드」를 함께 잰 값이다. 대상은 이야기, 시설 소개, 마지막 의뢰, 엔딩, 인증서다.
- 1절의 판정은 장면 묶음으로 한다. 인물은 대사를 말하는 화자라 놀이 영역에 포함한다. 기준 문서도 "프로젝트 고유 배치(장면 안 패널 등)는 유지"라고 정해 두었다.
- 활동 화면(`.activity-host`)과 지도(전체 화면 캔버스)는 패널 하나가 곧 놀이 영역이다.
- 시설 소개·활동·마지막 의뢰·엔딩·인증서는 저장 상태를 심어 직접 들어갔다. 다섯 시설 기록이 모두 있고 코어 복구까지 마친 상태다.

## 중복 조작 버튼

화면마다 보이는 조작 요소를 JS로 모두 뽑아(`measure.json`의 `btns`) 기준 2절의 유형과 대조했다.

| 위치 | 중복 내용 | 처리 |
|---|---|---|
| 기본 안내 창 7곳(교사용 빠른 이동, 친구들과 이야기, 탐구 기록 안내, 나의 개념 영상, 시연 종료, 엔딩 잠김, 인증서 잠김) | 오른쪽 위 X와 아래 「닫기」가 같은 일을 함 | `openDialog`가 X가 있으면 아래 「닫기」를 만들지 않음. X가 없는 창(`close:false`)은 그대로 「닫기」를 둠 |
| 설정 창 | X + 아래 「닫기」 | 아래 「닫기」 제거. 「탐구 기록 초기화」는 남김 |
| 나의 연구 가방 | X + 아래 「닫기」 | 아래 「닫기」 제거. 「기록 내려받기」는 남김 |
| 인증서 화면 | 「다른 방법으로 다시 탐구」와 왼쪽 위 뒤로 가기가 둘 다 지도로 감 | 「다른 방법으로 다시 탐구」 제거. 주 버튼은 「인증서 인쇄」 하나 |

없앤 버튼은 모두 10개다. 이야기·엔딩의 주 버튼 두 개는 지우지 않고 오른쪽 아래로 옮겼다.

### 중복이 아니어서 둔 것

- 활동의 「자동재생」 + 속도 선택: 속도는 재생 버튼과 다른 일을 하는 설정이다.
- 지도의 건물 이름표와 오른쪽 아래 「○○로 가기」: 이름표는 잠긴 시설을 포함한 다섯 곳 중 하나를 고르는 지도 표지다. 「가기」는 다음 차례 시설로 안내하는 유일한 주 버튼이다. 십자 이동 버튼, 전체 보기, 손 이동은 서로 다른 일을 한다.
- 시설 소개를 마친 뒤의 과제별 「다시」와 「다른 방법으로 다시 탐구」: 각각 다른 과제로 들어간다.
- 홈의 「에어 대사 다시 듣기」와 「에어와 친구들의 이야기 듣기」: 하나는 인사말을 다시 틀고, 다른 하나는 대화 창을 연다.
- 마지막 의뢰를 마치기 전에 주소로 바로 들어오면 보이는 「마을로 돌아가기」: 그 상태의 유일한 안내라 남겼다.
- 개념 영상 창(`src/concepts.js`)의 버튼은 「다시 보기」와 「다음」뿐이라 중복이 없다. 이 파일은 다른 세션의 자막 작업이 수정 중이라 어차피 건드리지 않았다.

## 바꾼 파일

- `src/stage-layout.css`: 맨 아래 「놀이 화면 비율·주 버튼 자리」 묶음
- `src/ui.js`: `openDialog`의 닫기 중복 제거
- `src/settings.js`: 설정 창 아래 「닫기」 제거
- `src/main.js`: 연구 가방 「닫기」와 인증서 「다른 방법으로 다시 탐구」 제거

학습 문구, 판정, 저장, 진행 로직은 바꾸지 않았다. `src/learning-ux.css`와 `src/concept*`는 다른 세션 작업이라 피했다.
